little-pip

A ~4.8M parameter character-level transformer. Same architecture as tinyPIP-0, scaled up. Zero build step. Open this file in any browser.

Parameter calculator

total parameters
MLP width is 4 x n_embd. Biases are off in linear layers. Output head is tied to the token embedding.

Parameter breakdown

token embedding (vocab x dim)
position embedding (block x dim)
attention qkv + proj (per layer)
MLP fc + proj (per layer)
layer norms (per layer)
all layers total
final layer norm
total

Architecture

tokens (vocab 65)
|
token embedding + position embedding
|
[ LayerNorm, causal self-attention, residual, LayerNorm, GELU MLP 4x, residual ] x n_layer
|
final LayerNorm
|
linear head (tied to token embedding)
|
next-character logits

Run it

pip install -r requirements.txt
python train.py                  # writes out/littlepip.pt
python train.py --eval-only      # report loss and perplexity
python generate.py --prompt "ROMEO:" --tokens 300
